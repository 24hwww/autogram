🗄️ Base de datos (SQLite)
Tabla images
CREATE TABLE images (
  id INTEGER PRIMARY KEY AUTOINCREMENT,
  prompt TEXT NOT NULL,
  caption TEXT,
  image_path TEXT NOT NULL,
  status TEXT CHECK(status IN ('pending','scheduled','published','failed')) NOT NULL,
  scheduled_at DATETIME,
  instagram_media_id TEXT,
  error TEXT,
  created_at DATETIME DEFAULT CURRENT_TIMESTAMP,
  published_at DATETIME
);

Tabla usage_limits
CREATE TABLE usage_limits (
  date TEXT PRIMARY KEY,
  images_generated INTEGER DEFAULT 0
);

🧠 Control de límites diarios (CRÍTICO)

Antes de generar una imagen:

Consultar:

SELECT images_generated FROM usage_limits WHERE date = DATE('now');


Si no existe → crear fila

Si images_generated >= DAILY_IMAGE_LIMIT:

Bloquear generación

Retornar error 429 Too Many Requests

Si permite:

Incrementar contador

Generar imagen con Gemini
